โค้ดพร้อมวาง

วางแต่ละชุดทั้งกล่องใน HTML Code คนละ Element ตามลำดับ HTML, CSS และ Script

ตั้ง SEO เฉพาะหน้าใน Magento
  1. ตั้ง URL Key ที่ CMS Page ใน Magento
  2. ตั้ง Meta Robots = NOINDEX, NOFOLLOW ในช่อง SEO ของหน้า หรือผ่านส่วนเสริมที่ตั้งตาม URL ได้
  3. ตั้ง Exclude from XML Sitemap = Yes หรือเพิ่ม URL Key นี้ในรายการ Exclude ของส่วนเสริม แล้วสร้าง Sitemap ใหม่
  4. ตรวจว่า source ของหน้าแสดง robots tag หรือ HTTP header ที่ถูกต้อง และ XML Sitemap ไม่มี URL นี้
หากร้านไม่มีช่อง SEO รายหน้า ให้ผู้ดูแลตั้ง Robots และ Sitemap สำหรับ URL นี้ โค้ด Page Builder ใส่ robots meta ในเนื้อหาให้เป็นตัวช่วยสำหรับ Google ส่วนการตัด URL ออกจาก XML Sitemap ต้องตั้งที่ Magento

คู่มือ Robots ของ Google · คู่มือ Sitemap ของ Adobe

โค้ดแคมเปญใช้กฎราคา คูปอง และของแถมที่ตั้งใน Magento อยู่แล้ว
