# Bewell Sale Page Config สำหรับขึ้นเว็บ

## เปิดตัวตั้งค่าหรืออัปโหลดขึ้นโฮสต์

เปิด `index.html` ในเบราว์เซอร์ หรืออัปโหลดไฟล์นี้เป็นหน้าเว็บแบบ Static ตัวตั้งค่ารวม HTML, CSS และ JavaScript ไว้ในไฟล์เดียวแล้ว

หากแก้ซอร์สใน `source/` ให้รัน `node build.cjs` จากโฟลเดอร์นั้น แล้วใช้ `source/dist/index.html` ที่สร้างใหม่

## นำหน้า Sale Page ขึ้น Magento

1. เปิดตัวตั้งค่าและกรอกข้อมูลแคมเปญของคุณ
2. เลือกโหมด **Live** และยืนยันคูปองหรือของแถมหลังตรวจว่ากฎใน Magento ตรงกับข้อเสนอ
3. กด **สร้างโค้ดทั้ง 3 ชุด** คัดลอก HTML, CSS และ Script ลงใน HTML Code คนละ Element ใน Page Builder แล้วบันทึก
4. ตั้ง URL Key ที่ CMS Page และตั้ง Exclude from XML Sitemap สำหรับหน้านั้นในระบบ SEO ของ Magento

## แก้ฟอนต์บน Sale Page ที่ขึ้นไว้แล้ว

เพิ่มเนื้อหาจาก `heading-font-patch.css` ไว้ท้ายกล่อง CSS เดิม **ก่อนแท็กปิด `</style>`** แล้วบันทึกหน้า ตัวแก้ระบุ Noto Sans Thai สำหรับ H1 ถึง H6 ภายใน Sale Page และใช้ฟอนต์ที่ธีม Bewell โหลดอยู่แล้ว

หากโค้ดที่ติดตั้งอยู่เป็นชุดที่สร้างจากตัวตั้งค่ารุ่นนี้ การส่งออก CSS จะมีตัวแก้ฟอนต์รวมอยู่แล้ว
